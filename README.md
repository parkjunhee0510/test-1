# 궤도 뛰기

탭 한 번으로 행성 궤도를 건너뛰는 브라우저 아케이드 게임입니다. 빌드 과정과 외부 의존성이 없습니다.

## 놀이 방법

- 우주선은 행성 주위를 돕니다. **탭**(또는 `Space`, `Enter`)하면 그 순간의 접선 방향으로 곧게 날아갑니다.
- 다른 행성의 점선 고리 안으로 들어가면 그 행성의 궤도에 걸립니다. 한 칸 전진할 때마다 1점입니다.
- 궤도는 돌수록 낮아집니다. 고도가 0이 되면 추락합니다.
- 어느 고리에도 닿지 못하면 우주 미아가 됩니다.
- 고리 바깥의 분홍 호가 남아 있을 때 떠나서 다음 행성에 걸리면 **연속**입니다. 연속 2번째부터 점수가 ×2, 최대 ×5까지 붙습니다.
- 행성 하나를 건너뛰어 그다음 행성에 걸리면 두 칸으로 계산합니다.

처음 몇 행성에서는 조준선이 고리에 닿는 순간 분홍으로 바뀌어 타이밍을 알려 줍니다. 뒤로 갈수록 행성은 멀어지고, 고리는 작아지고, 조준선은 짧아집니다.

## 실행

```bash
npm run dev
```

`http://localhost:5173` 을 엽니다. ES 모듈을 쓰기 때문에 `index.html`을 파일로 직접 열면 동작하지 않습니다.

| 주소 | 동작 |
| --- | --- |
| `/?seed=123` | 코스를 고정합니다. 같은 시드는 항상 같은 행성 배치입니다. |
| `/?auto=1` 또는 `/#demo` | 자동 조종 시연. 화면을 누르면 직접 조종으로 넘어갑니다. |

## 테스트

```bash
npm test
```

규칙 모듈의 단위 테스트입니다. Node 22 이상의 내장 테스트 러너만 씁니다.

```bash
npm run test:e2e
```

실제 브라우저로 게임을 띄워 입력, 재시작, 점수 표시를 확인합니다. Playwright가 필요합니다(`npm i -D playwright && npx playwright install chromium`). 폴더 경로를 인자로 주면 스크린샷을 남깁니다.

## 구조

| 파일 | 역할 |
| --- | --- |
| `src/logic.js` | 게임 규칙. DOM을 쓰지 않는 순수 모듈이라 Node에서 그대로 테스트합니다. |
| `src/render.js` | 캔버스 그리기와 연출. 색은 CSS 변수에서 읽어 밝은/어두운 테마를 따릅니다. |
| `src/audio.js` | Web Audio 발진기로 만드는 효과음. 음원 파일이 없습니다. |
| `src/main.js` | 입력, 게임 루프, 화면 글자. |
| `scripts/serve.mjs` | 개발용 정적 서버. |
| `test/`, `e2e/` | 단위 테스트와 브라우저 스모크 테스트. |

## 규칙을 이렇게 만든 이유

- **포획은 최근접점에서 일어납니다.** 그 순간 속도가 궤도 접선과 같아서 직선 비행이 원 궤도로 꺾임 없이 이어집니다. 행성 한가운데를 겨눈 경우에만 최저 고도에서 붙잡힙니다.
- **움직임은 닫힌 식으로 계산합니다.** 궤도는 로그 식으로, 비행은 직선으로 풀어서 프레임 간격에 따라 결과가 달라지지 않습니다. 탭도 입력이 들어온 시각까지 먼저 진행한 뒤 적용합니다.
- **코스는 항상 통과할 수 있습니다.** 포획 직후에도 최소 한 바퀴는 돌 수 있도록 수치를 잡았고, 자동 조종이 여러 시드에서 400개 이상의 행성을 죽지 않고 통과하는지 테스트로 확인합니다.

난이도 곡선은 `src/logic.js`의 `tune()` 한 곳에 모여 있습니다.
